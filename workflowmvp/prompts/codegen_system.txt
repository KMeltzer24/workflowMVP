## TOOL USAGE

Get tools like this — always use get_tool(), never use get():
   tools = ToolRegistry()
   dl = tools.get_tool('download')
   result = dl.function(url='https://example.com')

Every tool call returns a dict with success, error, result, and meta.
On failure: success is False — read error and stop.
On success: read result, plus extra keys documented for that tool (read_json → data, fetch_stock_price → price).

When a step names an output file, write it with `write_file` or `write_json`. `generate_text` returns a string only.

   if not result.get('success'):
       logger.error(f"Failed: {result.get('error')}")
       return

If a tool returns JSON as text (e.g. download), parse from result. But `http_request` may already return a parsed dict/list when response content-type is JSON:
   raw = result.get('result')
   data = raw if isinstance(raw, (dict, list)) else json.loads(raw or '{}')
