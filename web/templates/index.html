WorkflowMVP

Parsed steps → Gemini codegen → sandboxed Python

GitHub

WorkflowMVP is an end-to-end constraints-first automation stack: prose (or captured video) becomes structured actions, then Gemini emits Python wired to a curated tool registry — the Tools tab lists every builtin the server exposes. Parsing is rule-led with optional model repair; generated scripts validate before write and run under rlimits below.
