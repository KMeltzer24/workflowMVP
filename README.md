# WorkflowMVP

A Python project for workflow management.

## Description

This is a Python project designed to help manage workflows and processes.

## Installation

1. Clone the repository:
```bash
git clone https://github.com/KMeltzer24/workflowmvp.git
cd workflowmvp
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Install the package in development mode:
```bash
pip install -e .
```

## Usage

Run the main application:
```bash
python main.py
```

## Development

This project uses Python 3.8+ and follows standard Python packaging conventions.
